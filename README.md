# تطبيق إدارة المخزن والمبيعات
**Inventory & Sales Management App**

تطبيق موبايل متكامل يعمل بدون اتصال بالإنترنت (Offline-First) مخصص لإدارة المخزن والمبيعات، مطور بـ Flutter مع قاعدة بيانات SQLite محلية.

---

## 📋 المميزات الرئيسية

### 1️⃣ **إدارة المخزن والمنتجات**
- ✅ إضافة منتجات جديدة (الاسم، الكنية، الكمية الأولية، السعر)
- ✅ عرض قائمة بجميع المنتجات المتاحة
- ✅ تعديل بيانات المنتجات (الاسم، السعر، الكمية)
- ✅ حذف منتجات
- ✅ مؤشرات لكمية المخزن المنخفضة (أقل من 10)

### 2️⃣ **تسجيل المبيعات**
- ✅ اختيار المنتج من قائمة منسدلة
- ✅ إدخال الكمية المباعة
- ✅ تحديد سعر البيع (مع سعر افتراضي)
- ✅ حساب الإجمالي تلقائياً
- ✅ تحديث كمية المخزن تلقائياً عند البيع
- ✅ حفظ عملية البيع مع التاريخ والوقت

### 3️⃣ **التقارير والفلاتر**
- ✅ عرض مبيعات الشهر الحالي تلقائياً
- ✅ فلترة حسب نطاق زمني مخصص
- ✅ حساب إجمالي المبيعات
- ✅ عرض عدد العمليات
- ✅ حساب متوسط قيمة العملية
- ✅ عرض تفاصيل كل عملية بيع

## 📱 دليل الاستخدام

### شاشة إدارة المخزن 📦

#### إضافة منتج جديد:
1. انقر على زر **"+"** في أسفل الشاشة
2. أدخل بيانات المنتج:
   - **اسم المنتج**: مثل "أرز عادي"
   - **الاسم المستعار**: مثل "أرز"
   - **الكمية الأولية**: مثل 50
   - **السعر**: مثل 25.50
3. انقر **"حفظ"**

#### تعديل منتج:
1. انقر على الثلاث نقاط بجانب المنتج
2. اختر **"تعديل"**
3. غيّر البيانات المطلوبة
4. انقر **"حفظ التغييرات"**

#### حذف منتج:
1. انقر على الثلاث نقاط بجانب المنتج
2. اختر **"حذف"**
3. أكّد الحذف

---

### شاشة إدخال البيع 🛒

#### تسجيل عملية بيع جديدة:
1. اذهب إلى تبويب **"بيع جديد"**
2. اختر المنتج من القائمة المنسدلة
3. أدخل **الكمية المباعة**
4. أدخل **السعر** (يُملأ تلقائياً بالسعر الافتراضي)
5. سيُحسب **الإجمالي** تلقائياً
6. انقر **"تأكيد البيع"**
7. راجع التفاصيل وانقر **"تأكيد"** للحفظ

**ملاحظات:**
- لا يمكنك بيع كمية أكثر من المتاح في المخزن
- الكمية تُطرح تلقائياً من المخزن عند تأكيد البيع
- يمكنك تعديل السعر إذا اختلف عن الافتراضي

---

### شاشة التقارير 📊

#### عرض مبيعات الشهر الحالي:
1. اذهب إلى تبويب **"التقارير"**
2. سيتم عرض المبيعات تلقائياً بشكل افتراضي

#### عرض مبيعات فترة مخصصة:
1. انقر على **"من التاريخ"** واختر التاريخ الأول
2. انقر على **"إلى التاريخ"** واختر التاريخ الأخير
3. انقر **"بحث"** للعرض

#### البيانات المعروضة:
- 📈 **إجمالي المبيعات**: المبلغ الكلي
- 🔢 **عدد العمليات**: عدد المبيعات
- 💰 **متوسط العملية**: الإجمالي ÷ عدد العمليات
- 📋 **قائمة تفاصيلية**: لكل عملية بيع

## 💾 هيكل قاعدة البيانات

### جدول المنتجات (Products)
```sql
CREATE TABLE products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  nickname TEXT NOT NULL,
  stock_quantity REAL NOT NULL,
  price_per_unit REAL NOT NULL
)
```

**الحقول:**
- `id`: معرف فريد تلقائي
- `name`: اسم المنتج (مثل "أرز عادي")
- `nickname`: الاسم المستعار (مثل "أرز")
- `stock_quantity`: الكمية المتاحة (كيلو أو قطعة)
- `price_per_unit`: السعر لكل وحدة

---

### جدول المبيعات (Sales)
```sql
CREATE TABLE sales (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  product_id INTEGER NOT NULL,
  product_name TEXT NOT NULL,
  quantity_sold REAL NOT NULL,
  unit_price REAL NOT NULL,
  total_price REAL NOT NULL,
  created_at TEXT NOT NULL,
  FOREIGN KEY (product_id) REFERENCES products (id)
)
```

**الحقول:**
- `id`: معرف العملية
- `product_id`: معرف المنتج المباع
- `product_name`: اسم المنتج (للمرجعية)
- `quantity_sold`: الكمية المباعة
- `unit_price`: سعر البيع
- `total_price`: الإجمالي (الكمية × السعر)
- `created_at`: التاريخ والوقت (ISO 8601)

## 🐛 استكشاف الأخطاء

### المشكلة: التطبيق لا يبدأ
**الحل:**
```bash
flutter clean
flutter pub get
flutter run
```

### المشكلة: قاعدة البيانات لا تحفظ البيانات
**الحل:**
- تأكد من تثبيت `sqflite` و `path_provider`
- احذف التطبيق وأعد تثبيته

### المشكلة: الواجهة لا تحدّث البيانات
**الحل:**
- تأكد من استخدام `Provider` بشكل صحيح
- تحقق من أن `notifyListeners()` يُستدعى بعد كل عملية
